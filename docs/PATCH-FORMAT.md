# GVKR0901

V0.9 EXE의 `GV.patch` 리소스는 gzip으로 압축된 데이터 차분입니다.
내장 데이터의 SHA-256을 확인한 후 다음 형식으로 해석합니다.
별도 실행 프로그램을 추출하거나 실행하지 않습니다.

| 필드 | 크기 |
| --- | --- |
| ASCII `GVKR0901` | 8바이트 |
| 원본 ISO 크기 | Int64, little-endian |
| 결과 ISO 크기 | Int64, little-endian |
| 원본 SHA-256 | 32바이트 |
| 결과 SHA-256 | 32바이트 |

| 명령 | 매개변수 | 동작 |
| --- | --- | --- |
| `0x00` | Int64 오프셋 + UInt32 길이 | 원본에서 복사 |
| `0x01` | UInt32 길이 + 데이터 | 변경 데이터 기록 |
| `0x02` | UInt32 길이 | 0으로 채운 영역 기록 |
| `0xFF` | 없음 | 끝 |

명령에는 파일 이름이나 실행 지시가 없습니다. 원본·출력 범위, 명령 개수,
종료 위치와 최종 ISO SHA-256을 검사합니다. 출력은 새 `.partial` 파일에
작성하고 검증을 통과한 뒤 요청한 새 파일 이름으로 이동합니다.
원본이나 기존 출력 파일을 덮어쓰지 않습니다.

`tools/make_patch.py`는 지원하는 두 ISO를 사용해 결정적인 패치 데이터를
재생성합니다. 원래 파일 배치를 보존한 두 ISO의 64바이트 블록을 비교합니다.
변경 없는 블록은 원본 참조로 기록합니다. gzip 시간과 파일 이름은 고정합니다.

패처 소스는 Windows의 .NET Framework C# 컴파일러로 빌드할 수 있습니다.
Python과 NumPy는 차분 재생성 도구에서만 사용하며 배포 EXE에는 필요 없습니다.
